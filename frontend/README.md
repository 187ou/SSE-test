# ADP 对话台 - 前端说明

## 极简版前端

已移除所有对话管理功能，直接开始对话！

### 功能

✅ **纯对话界面**
- 无侧边栏
- 无对话列表
- 无创建/删除操作
- 直接输入消息

✅ **核心功能**
- 流式显示AI回复
- 打字动画指示器
- Enter快捷发送
- 自动滚动到底部
- 渐变色UI设计

### 使用方式

#### 方式一：直接打开（推荐）

双击 `index.html` 即可在浏览器打开

#### 方式二：本地服务器

```bash
cd frontend
python -m http.server 3000
# 访问 http://localhost:3000
```

#### 方式三：一键启动

```bash
start-all.bat
```

### 界面说明

```
┌─────────────────────────────────────────┐
│  ● AI 助手                               │  ← 头部
├─────────────────────────────────────────┤
│                                         │
│  你好！有什么可以帮助你的吗？            │  ← 消息区
│                                         │

│  AI: 你好！很高兴见到你...               │
│                                         │
├─────────────────────────────────────────┤
│ [输入消息...                 ] [发送]   │  ← 输入区
└─────────────────────────────────────────┘
```

### 消息类型

- **用户消息** - 右侧紫色渐变气泡
- **AI消息** - 左侧白色气泡 + 打字动画

### 快捷键

- `Enter` - 发送消息
- `Shift + Enter` - 换行

### 特性

- ✅ 渐变色主题
- ✅ 平滑动画
- ✅ 响应式设计
- ✅ 打字动画指示器
- ✅ 流式消息显示
- ✅ 自动滚动

### API配置

默认连接后端地址：`http://localhost:8080/api/chat`

如需修改，编辑 `index.html` 第598行：

```javascript
const API_BASE = 'http://localhost:8080/api/chat';
```

### 注意事项

⚠️ 确保后端服务已启动（端口 8080）

```bash
# 启动后端
run-backend.bat

# 或手动启动
mvn spring-boot:run --server.port=8080
```
